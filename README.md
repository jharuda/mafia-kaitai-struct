# mafia-kaitai-struct

## Introduction

This repository contains [kaitai-struct](https://kaitai.io/) definitions for binary file formats of the video-game [Mafia](https://en.wikipedia.org/wiki/Mafia_(video_game)) also known as *Mafia: The city of Lost Heaven*.

Kaitai-struct is a declarative Domain Specific Langage (DSL) that uses YAML syntax in definitions. There is [the existing library](https://github.com/kaitai-io/kaitai_struct_formats) of 
binary reversed file formats.


## Authors

Those `kaitai-struct` Mafia sources in this repository were developed mostly with knowledge of already 
existing reverse engineered pieces of C++ source code and header files in the [OpenMF repository](https://github.com/MafiaHub/OpenMF-Archived) and knowledge taken from russian page MafiaPub. OpenMF
[authors can be found in this link](https://github.com/MafiaHub/OpenMF-Archived/blob/master/AUTHORS.md).

Jakub 'Harry' Haruda is a main author of `Mafia Kaitai struct` definitions.
